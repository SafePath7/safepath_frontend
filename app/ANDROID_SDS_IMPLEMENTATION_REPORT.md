# Android SDS 구현 및 검증 기록

기준: SafePath_SDS_최종 (2).pdf, SafePath_Android_10-13주차_주차별_작업계획.pdf
작업 범위: 휴대폰 app 모듈. backend/, 별도 Spring 저장소, wear/ 수정 없음.
기존 LAN 테스트 등 미커밋 변경사항 유지. 이 문서는 전체 SDS 완료 선언이 아니다.

## 구현

| 문서 근거 | 변경 | 구현 방식 |
|---|---|---|
| UI-08, FD-006/019 | 감지 설정 네 항목 | 계정별 SharedPreferences 저장, 다음 세션 요청 도메인 모델에 포함. AI 서버 활성화로 표시하지 않음 |
| 11주차 경로 선택 | 추천 경로 기본 선택 | Pager initialPage=1 |
| UI-05, FD-006 | 수락된 보호자만 선택 | 기존 로컬 연락처 대신 서버 수락 친구 캐시 사용. 서버 최종 권한 검사는 별도 필요 |
| UI-05 | PIN 화면 복원 저장 제외 | rememberSaveable 대신 remember. 기존 LAN 테스트에는 인증 미연결임을 명시 |
| UI-07, SDS 6.3 | 최근 일반 귀가 기록 제거 | 일반 세션 비보관 원칙 적용 |
| UI-07 | 위험 우선 정렬·안정적 선택 | 위험→의심→이탈→기타 정렬, 배열 index 대신 sessionId로 상세 선택 |
| 10/12주차 구조 | 세션·긴급 Repository 계약 | 화면과 구분된 도메인 요청/상태/위치 모델. 서버 wire DTO 확정으로 주장하지 않음 |
| FD-006/007 | 로컬 시작·종료 | 경로/보호자/PIN 검증, 중복 시작 차단, 솔트 해시로 모의 PIN 비교, 5회 실패에도 세션 유지 |
| FD-008 | 위치 순서·오프라인 모의 | 좌표 범위/정확도 검증, 오래된 위치로 최신 위치 덮어쓰기 차단, 메모리 임시 위치 순서대로 재반영 |
| FD-011/019 | 모의 SOS·위험 질문 | 길게 눌러 위험 전환, 진동·대화상자·30초 시험용 마감, 추가 질문으로 마감 연장 금지, 늦은 응답 거부, 인증 해제 |
| 12주차 | 휴대폰 Foreground Service | 위치/알림 권한 요청, 수집 알림, GPS·네트워크 위치 수집, 명시적 종료, START_NOT_STICKY |
| 13주차 | 디버그 로컬 시연 | 로그인 화면 모의 시연 진입 및 debug-only intent 진입. 실제 푸시/신고 없음 표시 |
| 10/13주차 권한 | 설정 진입 | 마이크 목적 안내와 앱 권한 설정, 알림 설정 연결 |

## 로컬 시연

로그인 화면 → 서버 없이 로컬 시연 → 샘플 경로 선택 → 샘플 보호자 선택 → 4자리 PIN → 모의 시작 → 샘플 위치 이동 → 보호자 역할 보기 → SOS 길게 누르기 → PIN으로 해제/종료.

추가 시나리오: 네트워크 끊기→샘플 이동→연결 복구, 위험 질문→괜찮아요/도와주세요/30초 무응답, PIN 5회 불일치.

실제 GPS 수집 시험 버튼은 기기 위치를 수집하지만 네트워크로 전송하지 않는다. 시연 화면을 벗어나면 수집을 종료한다. 프로세스 종료 후 모의 세션 복원은 지원하지 않으며 이를 화면에 명시했다.

디버그 진입 명령(운영 빌드는 무시):

```text
adb shell am start -n com.example.safepath_test1/.MainActivity --ez local_demo true
```

## 검증

- app assembleDebug 성공.
- app testDebugUnitTest: 16개 통과, 실패 0. 신규 세션 테스트 6개 포함.
- app lintDebug 성공. 마지막 완료 결과 오류 0, 경고 33(기존 의존성/스타일 및 디버그 HTTP 허용 등).
- 에뮬레이터 실행 시도 실패: 기존 Pixel_10_Pro config.ini 읽기 실패 및 ARM/QEMU2 architecture 오류. 따라서 화면 실측·스크린샷·실기기 GPS/백그라운드 검증은 미완료.
- 개인 휴대폰/워치에 설치하거나 데이터를 변경하지 않음.

## 완료로 간주하지 않는 항목

- 운영 API 인증/세션 생성/위치 업로드/종료/긴급 이벤트 및 FCM 토큰 등록·푸시 수신.
- 보호자 WebSocket 실시간 갱신·재연결과 두 기기 통합 검증.
- 디스크 기반 오프라인 위치 큐 및 프로세스 재시작 복구. 현재 시연은 메모리 큐만 제공.
- 기존 홈 LAN 테스트를 정식 세션 Repository로 교체하는 작업. 기존 서버의 인증/종료 계약을 임의 변경하지 않음.
- SDS 4종 시설 레이어 및 서버 경로 DTO 연동. 기존 CCTV/가로등 프로토타입과 차이가 남아 있음.
- 운영 응답 대기 기본값/범위(TBD-6), 전송 주기(TBD-1), 생체 challenge(TBD-23)는 미합의. 30초/5초는 로컬 시험 값이며 운영값 아님.
- 위험 질문의 운영 알림·푸시 탭 연결, 음성 녹음·프로필, 경로 후기/점수 근거/공유 링크는 미구현 또는 API 미합의. 질문 대화상자·진동은 구현했으나 실제 기기 동작은 미검증.
- 워치 관련 수정·연동 구현은 사용자의 제외 지시에 따라 수행하지 않음.

서버 구현이 필요하지 않은 UI·모의 데이터 작업도 더 남아 있으므로 10~13주차 전체 완료로 표시하지 않는다.
