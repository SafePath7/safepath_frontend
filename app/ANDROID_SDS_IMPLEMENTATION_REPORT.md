# Android SDS 구현 현황

기준: SDS 최종 (2), Android 10~13주차 계획.

## 현재 기능

Google/Firebase 로그인과 추가 정보 입력, 취소·네트워크 오류 안내, 친구 API 401 로그인 복귀, AuthRepository/FriendsDataSource 계약과 주소·토큰 주입형 Retrofit 생성 함수를 유지한다.

계정별 감지 설정과 응답 대기 시간을 기기에 저장한다. 앱 기본 응답 시간은 30초이며 서버 정책·실제 전송은 후속 연동에서 조정한다. 추천 경로 기본 선택, 수락된 보호자 선택, 세션 ID 기반 보호 화면 선택, 권한 안내를 유지한다.

홈에서 시작하는 LAN 간이 테스트와 보호자 웹 연결은 유지한다. 실제 위치·선택 경로·경로 종류를 개인 Wi-Fi의 테스트 서버에 전달한다. 운영 세션·긴급 알림·종료 비밀번호 인증과는 구분한다.

## 첫 화면 모의 시연 제거

사용자 요청에 따라 로그인 화면의 서버 없는 로컬 시연과 Activity intent 진입을 제거했다. 전용 화면·ViewModel·FakeSessionRepository·위험 질문 대화상자·GPS 수집 시험 서비스와 선언·전용 권한·모의 세션 테스트 6개를 제거했다.

샘플 경로·보호자, 모의 위치 이동·오프라인 큐·SOS·위험 확인·비밀번호 종료 시연은 더 이상 제공하지 않는다. 감지 설정과 향후 연동용 세션 도메인 계약, 기존 LAN 간이 테스트와 워치 코드는 유지한다.

## 후속 작업 및 검증 기준

Spring 회원·보호자·세션·위치·SOS·FCM API와 보호자 WebSocket 연동은 미완료이며 실제 서버 주소와 명세가 필요하다. 실기기 앱흐름 테스트는 사용자 완료 확인을 반영한다. 자동 검증에서 삭제한 모의 테스트 6개를 현재 통과 수에 포함하지 않는다.
