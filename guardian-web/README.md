# SafePath 웹 뷰어 (앱 디자인 통일 버전)

SafePath SDS의 UI-01~UI-09 화면 디자인을 참고하여 흰색 배경, 진한 네이비 버튼/텍스트, 녹색 정상 상태, 빨간색 위험 상태, 약 12px 카드 모서리로 구성한 읽기 전용 웹 뷰어 데모입니다.

## 실행

### Android와 같은 Wi-Fi에서 간이 테스트

이 방법은 실제 위치가 암호화되지 않은 HTTP로 같은 네트워크에 전송되는 **디버그 전용 테스트**입니다. 신뢰할 수 있는 개인 Wi-Fi에서만 사용하고, 공용 Wi-Fi나 인터넷에 포트를 공개하지 마세요. 긴급 신고와 보호자 알림은 제공하지 않습니다. 디버그 앱에만 HTTP 허용 설정이 적용됩니다.

1. PC와 Android 기기를 같은 Wi-Fi에 연결합니다. 이 폴더에서 `npm install` 후 `node start-test.cjs`를 실행하고 터미널을 켜 둡니다. 이 명령은 Android 프로젝트 설정에 새 테스트 토큰을 자동으로 기록합니다.
2. 출력된 웹 링크를 PC 브라우저에서 엽니다. 지도 배경을 보려면 아래 Mapbox 공개 토큰 설정이 필요합니다.
3. 처음 사용할 때 Android 프로젝트의 `local.properties`에 `SAFEPATH_TEST_URL=http://PC의-Wi-Fi-IP:8080/`을 추가합니다. 여러 IP가 표시되면 같은 Wi-Fi의 PC IPv4 주소를 사용합니다. 에뮬레이터에서는 PC 주소 대신 `http://10.0.2.2:8080/`을 사용합니다. 기존 속성은 유지하세요. 이 주소를 설정한 다음 1번 명령을 실행하면 토큰이 자동 설정됩니다.
4. Android Studio에서 상위 폴더(`..`)를 열고 Gradle 동기화 후 **debug** 앱을 빌드·설치합니다. Kakao/Mapbox 키 및 Google 로그인 설정은 Android 프로젝트 README를 따릅니다. 테스트 서버를 다시 켤 때마다 토큰이 자동 갱신되므로 앱을 다시 빌드해야 합니다.
5. 앱의 위치 권한을 허용하고 경로를 검색해 **이 경로로 출발 준비**를 선택합니다. 기존 화면의 보호자 선택과 종료 비밀번호 4자리를 입력한 뒤 **안전귀가 시작 (간이 테스트)**을 누릅니다. 성공하면 웹에서 현재 위치와 이후 갱신이 표시됩니다. 위치를 아직 받지 못했다면 수신될 때까지 기다리세요.
6. 같은 화면에서 **간이 테스트 종료**를 누르면 웹 위치가 지워지고 링크가 폐기됩니다. 다시 시험하려면 서버를 재시작하고 새 링크와 토큰으로 앱을 다시 빌드합니다. 연결이 안 되면 주소, Windows 방화벽의 포트 8080 허용 여부, 같은 Wi-Fi 연결 및 앱의 위치 권한을 확인하세요.

이 서버는 한 번에 한 세션만 메모리에 유지하며 앱이 전경에서 기존 위치 콜백을 받을 때만 갱신합니다. 서버 종료 시 데이터가 사라집니다. GPS·네트워크가 중단된 상태에서의 종료 보장, 백그라운드 위치, SOS 및 위험 감지 연동은 구현하지 않았습니다.

### 기존 웹 전용 실행

`index.html`, `style.css`, `app.js`, `viewer.js`, `config.js`를 같은 폴더에 두고 정적 HTTP 서버로 실행합니다. LIVE 모드는 같은 출처의 백엔드와 HTTPS가 필요하며 localhost HTTP는 개발에만 허용합니다. 자세한 실행법과 제안 계약은 [연동 문서](INTEGRATION.md)를 참조하세요. 지도 타일과 Leaflet 라이브러리는 인터넷 연결이 필요합니다.

지도 배경은 Mapbox를 사용합니다. [Mapbox 액세스 토큰 페이지](https://account.mapbox.com/access-tokens/)에서 공개 토큰(`pk.`로 시작)을 만든 뒤 `index.html`의 `<meta name="mapbox-token" content="" />`에서 `content`에 입력하세요. 비밀 토큰(`sk.`)은 사용하지 마세요. 토큰이 없으면 경로와 마커는 표시되지만 지도 배경은 표시되지 않습니다. 배포 시 공개 토큰에 사이트 URL 제한을 설정하고, 제한된 토큰은 해당 사이트 주소로 접속해 사용하세요. Mapbox Static Tiles API는 요청량에 따라 요금이 발생할 수 있습니다.

## 데모

`config.js`에서 데모를 명시적으로 활성화하고 localhost에서 `#mode=demo`로 접속하면 가상 위치 이동, 위험 상황 및 세션 종료를 시험할 수 있습니다. 운영에서는 데모를 비활성화하세요. 실제 위치, 인증, 서버 알림과 연결되지 않습니다.

## 실서비스 연동

공유 토큰을 서버에서 검증하고, 읽기 전용 위치 및 세션 상태만 권한 검증된 WebSocket으로 전달하세요. 공유 중지/세션 종료 시 토큰을 즉시 무효화해야 합니다. SDS의 공유 링크 API는 아직 TBD-23입니다.
