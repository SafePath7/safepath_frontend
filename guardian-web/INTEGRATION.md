# SafePath 실시간 공유 연동

Android 저장소의 Firebase 백엔드는 친구 초대용입니다. 안전귀가 세션, 위치 전송, 공유 링크, 위험 이벤트 및 웹 구독 운영 서버는 확인되지 않았습니다. 별도로 추가한 `test-server.cjs`는 같은 Wi-Fi의 단일 세션 간이 테스트 전용이며 실행법은 README에 있습니다. 아래 LIVE 계약은 **제안**이며 운영 서버 API나 확정된 SDS 사양이 아닙니다. SDS 최종본은 이 작업에서 확인하지 못했습니다.

## 실행

웹 폴더에서 `npx http-server -p 8080` 등 정적 HTTP 서버를 시작하고 Chrome에서 `http://localhost:8080/`을 엽니다. `npx`를 쓴다면 패키지 다운로드가 필요할 수 있습니다. 파일을 직접 열면 LIVE가 작동하지 않습니다. 운영은 HTTPS가 필요합니다. Mapbox 공개 토큰을 `index.html`의 `mapbox-token` 메타 태그에 설정하세요. Leaflet은 unpkg CDN, 지도 이미지는 Mapbox Static Tiles API를 사용하며 인터넷이 필요합니다. 비밀 토큰은 넣지 마세요. 운영 시 공개 토큰에 도메인 제한을 설정하세요. 타일 요청량에 따라 요금이 발생할 수 있습니다.

LIVE는 기본 모드이며 서버가 생성한 링크의 `#token=공유토큰`을 읽습니다. 토큰은 주소창에서 제거하고 메모리에서만 사용합니다. 동일 출처의 API와 WebSocket을 사용하므로 개발 시 웹과 백엔드 앞에 같은 출처의 리버스 프록시가 필요합니다. 연결 실패 시 데모 데이터로 대체하지 않습니다.

DEMO는 로컬 전용입니다. `config.js`의 `enableDemo`를 `true`로 바꾸고 `http://localhost:8080/#mode=demo`에 접속하세요. 가상 이동, 일시정지, 위험 전환, 종료 및 초기화를 시험할 수 있습니다. 운영 배포에서는 `false`를 유지하세요. 데모는 실시간 공유나 SOS 전송이 아닙니다.

## 제안: 웹 읽기 전용 서버 계약

경로와 형식은 백엔드와 합의 후 변경해야 합니다. 응답에 `Cache-Control: no-store`를 적용하고 각 요청과 구독을 인증·인가합니다.

* `POST /api/viewer/session`: `Authorization: Bearer <공유토큰>`으로 최신 허용 스냅샷 조회. 만료·철회는 401/403/404/410 중 하나. 그 외 오류는 재시도합니다. POST는 토큰을 URL에 넣지 않기 위한 읽기 전용 조회입니다.
* `wss://동일출처/ws/viewer`: 첫 메시지 `{"type":"authenticate","token":"..."}`. 검증 전 위치를 전송하지 않습니다. 성공 시 `{"type":"authenticated"}`, 이후 아래 형식에 `"type":"snapshot"`을 추가한 메시지를 전송합니다. 철회·만료·인증 실패 시 `{"type":"expired"}` 전송 후 연결을 닫습니다. 서버 측 인증 제한 시간, Origin 검증, 접속 제한이 필요합니다.
* 최초 조회 뒤 구독을 인증하고 다시 조회합니다. 서버는 구독 인증 완료 이전의 변경도 두 번째 조회에 반영해야 합니다. 세션별 `sequence`는 모든 스냅샷과 이벤트에서 단조 증가해야 합니다. 클라이언트는 중복·오래된 sequence를 무시하고 재접속 시 다시 조회합니다.

```json
{"sequence":42,"status":"MOVING","location":{"latitude":35.85,"longitude":128.49,"accuracyMeters":12,"updatedAt":"2026-11-04T10:00:00Z"}}
```

위치가 아직 없으면 `location`은 `null`입니다. `status`는 `MOVING`, `OFF_ROUTE`, `SUSPECTED`, `DANGER`, `SOS`, `ARRIVED`, `CANCELLED`, `ENDED`, `EXPIRED` 중 하나입니다. 종료 상태를 받으면 지도 위치와 경로를 지우고 재접속을 중단합니다. 위치 시각이 60초를 넘으면 갱신 지연으로 표시하며 위험으로 판정하지 않습니다. 이력은 웹 페이지에서 수신한 위치 최대 1,000개만 메모리에 보관하고 종료 시 지웁니다. 거리, 진행률, 출발지, 목적지는 계약이 없어 표시하지 않습니다.

서버는 세션별 충분한 엔트로피의 토큰을 발급하고 안전하게 보호하며 공유 중지/세션 종료 시 원자적으로 폐기하고 기존 구독을 끊어야 합니다. 로그·프록시·분석 도구에서 Authorization, WebSocket 인증 메시지, 토큰 및 위치를 기록하지 않도록 해야 합니다. 공유된 최소 정보만 반환하고 사용자 인증, 세션 소유권, 토큰별 접근 제한, 철회 경쟁 조건, 보존 및 삭제 정책을 서버에서 강제해야 합니다. `ARRIVED`도 위치 공개가 끝나는 종료 상태로 제안합니다. 서버가 오프라인인 동안 철회 여부를 웹에서 알 수 없으므로 지연 표시는 서버 철회 보장을 대신하지 않습니다.

## Android와 백엔드 후속 구현

Android에는 `LocationManager` 전경 위치 수집(5초/5m 요청), 경로 검색, 사용자가 대상을 선택하는 SOS 공유 시트가 있습니다. 기존 운영 세션 시작/종료, 위치 서버 전송, 공유 링크 발급 및 AI 위험 수신은 확인되지 않았습니다. 간이 테스트 연결은 별도 디버그 설정을 사용하며 운영 세션이 아닙니다. 기존 Retrofit은 시설 조회 전용이고 Firebase Functions는 친구 초대 전용입니다.

서버는 인증된 앱의 세션 생성·종료, 위치 전송, 상태/SOS 수신, 공유 발급·폐기와 위 뷰어 계약을 구현해야 합니다. 요청에 제시된 `/api/safe-return/sessions`, `/api/locations`, `/api/v1/emergencies`, `/ws/locations` 등의 실제 구현과 메시지 형식은 확인되지 않았습니다. API 및 앱 UI/백그라운드 위치 정책을 확정한 뒤 기존 위치 리스너와 세션 생명주기에 연결해야 합니다. AI 의심과 SOS/확정 위험은 서버에서 구분하여 전달해야 합니다.

Android Studio에서는 상위 폴더(`..`)를 열고 SDK/Gradle 동기화 후 해당 프로젝트 README의 Kakao·Mapbox·Firebase 설정을 적용해 실행합니다. 기기 위치 권한이 필요하며 실기기에서 전경/백그라운드 동작을 별도 검증해야 합니다.
