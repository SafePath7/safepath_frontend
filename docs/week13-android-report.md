# SafePath 13주차 Android 개발 보고서
기간 2026년 11월 24일~30일 · 임건우 · 11월 24일 작업 기준

| 항목 | 구현 및 검증 결과 |
|---|---|
| 세션 SOS | 길게 누르기, 전송 전 취소, 서버 발송 결과 및 현재 위치 표시. 발송 후 보호자에게 해제 통지를 보낼 API는 없음. |
| 보호자 알림 | SOS·위험·세션 시작·종료 처리. 알림 대상과 조회 권한이 일치하는 활성 세션을 열고 종료 세션은 안내. GPS 도착 푸시는 별도 서버 이벤트 필요. |
| 위험 확인 | 디버그 모의 위험 질문, 진동, 설정 시간에 따른 카운트다운, 안전·도움·무응답 분기. |
| 워치의 폰 측 처리 | SOS 수신 확인 및 사용자 확인 후 보호자 전송. 실제 이벤트 ID·세션·대기 상태를 확인해 워치 응답을 서버에 반영. |
| 종료 보안 | 4자리 PIN 확인, 오류 횟수 및 5회 이상 실패 안내. |
| 빌드·검증 | 폰 디버그 APK 생성 및 기존 JVM 단위 테스트 통과. 오프라인 위치 큐의 재개방·사용자 격리·전송 확인 삭제를 검사하는 Android 계측 테스트 추가 및 테스트 APK 빌드 성공. |
| 통합 시험 | x86_64 에뮬레이터에서 카카오 지도 네이티브 라이브러리가 없어 앱이 종료되는 문제를 수정했다. 지도 초기화에 실패하면 지도 영역에 안내를 표시한다. Android 계측 테스트 2개 통과. 위치·알림 권한을 거부한 뒤 앱이 열린 상태를 확인했다. 백그라운드에서 네트워크를 끊고 앱을 복귀시킨 뒤 연결을 복구해 같은 앱 프로세스가 유지됨을 확인했다. 인증된 귀가 세션의 WebSocket 재구독, 대기 위치의 서버 전송, 실제 푸시·워치 통신은 미검증. |

시연 절차는 같은 폴더의 week13-phone-demo.md에 정리했다.
