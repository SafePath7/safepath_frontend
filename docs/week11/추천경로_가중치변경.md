# 추천 경로 비율 변경

사용자 요청에 따라 추천 경로의 안전 : 시간 효율 비율을 6.5 : 3.5로 변경했다.

- 최종 추천 점수: 정규화된 시설 안전 지표 × 0.65 + 정규화된 시간 효율 × 0.35.
- 시설 격자에서 추천 성향의 경유 후보를 생성할 때도 안전 가중치 0.65를 사용한다.
- 최단은 예상 시간 최소, 안전은 시설 지표 최대를 선택하는 기준을 유지한다.
- 이전 PDF 보고서에 적힌 50:50 및 추천 후보 생성 가중치 0.5는 이 변경 이전의 기록이다.

회귀 사례: 시간 100/110/130초, 시설 지표 0/50/100이면 기존 50:50은 중간 후보를 선택하지만, 변경 후 65:35는 가장 안전한 후보를 추천한다. 절충 후보가 충분히 안전하고 빠르면 추천 결과가 안전·최단과 다를 수 있다.
