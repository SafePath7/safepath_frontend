# 경로의 왕복·반복 구간 방지

- 경유 후보는 Douglas-Peucker 방식으로 간소화한다. 허용 오차는 출발-도착 직선거리의 2%를 25~80m로 제한한다.
- 출발·도착 30m 이내의 불필요한 경유지, 목적지를 지나치거나 이전 경유지보다 뒤로 돌아가는 경유지를 제외한다. 내부 경유지는 최대 8개다. 옆으로 우회하는 주요 굴곡과 출발·도착 좌표는 유지한다.
- 보행 요청에 `continue_straight=true`, `waypoints=0;마지막인덱스`를 적용한다. 시설 경유지를 개별 도착지처럼 취급하지 않도록 한다.
- 반환된 실제 보행 선을 약 5m 간격으로 표본화한다. 최소 30m 전에 지난 선과 3m 이내에서 같은 축으로 20m 이상 연속 겹치는 구간을 탐지한다. 양방향 왕복과 같은 방향 재통과를 모두 검사한다.
- 기존 경로 꼭짓점으로 40m 이상 이동한 후 같은 지점 1m 이내로 돌아오는 닫힌 우회도 제외한다. 한 번 교차하는 선이나 12m 떨어진 평행 도로, 작은 좌표 흔들림은 회귀 테스트에서 허용한다.
- 시설 우회 응답에 반복 구간 또는 명시적 U턴 안내가 있으면 경유지를 절반으로 줄여 한 번만 재조회한다. 제거할 경유지가 없으면 검증된 기본 보행 후보를 사용한다. 모든 후보가 부적합하면 오류 상태로 남긴다.
- 표시용 GeoJSON을 임의로 잘라 붙이지 않는다. 시간·거리·회전 안내는 API가 반환한 같은 경로의 값을 사용한다.
- 추천의 안전 65%·시간 효율 35%, 원형 시설 분석, wear 수정 금지 조건은 유지한다.

검증: 왕복, 다른 꼭짓점 간격의 역주행, 닫힌 우회, 정상 측면 우회, 평행 도로, 단일 교차, 작은 좌표 흔들림, 경유지 간소화 및 기존 시설 우회 테스트 통과. 앱 단위 테스트 및 APK 빌드 성공.

한계: 위치 기반 근사 검증이며 도로 ID나 층 정보를 이용한 판정은 아니다. 매우 가까운 평행 길이나 입체 교차에는 오탐 여지가 있고, 20m 미만의 짧은 왕복을 전부 금지하지 않는다. 온라인 실제 경로 사례는 별도로 확인해야 한다.

API 근거: https://docs.mapbox.com/api/navigation/directions/ 의 continue_straight 및 waypoints 설명.
