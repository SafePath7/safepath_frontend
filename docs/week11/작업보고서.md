# 공공데이터 처리와 시설 분석

CCTV 원본 377,278행 중 좌표 누락·범위 오류 21행을 제외하고, 소수점 6자리 좌표 기준 중복 125,270행을 제거했다. 최종 251,987개 좌표를 반영했다. 여러 카메라가 같은 좌표에 있어도 한 시설 위치로 계산하며 카메라 대수를 합산하지 않는다.

가로등 파일은 열 이름상 보안등 자료다. 50,000행 중 좌표 누락·범위 오류 17,642행을 제외하고 중복 3,706행을 제거해 28,652개 좌표를 반영했다. 기존 가로등 자료와 단순 병합하면 출처·중복 기준이 달라질 수 있어 제공 자료로 교체했다. 제공 범위 밖 시설은 누락될 수 있다.

원본은 CP949로 읽고 위도 30~40도·경도 120~135도, 숫자 파싱 여부를 검사했다. 위경도 6자리 좌표를 정렬한 UTF-8 CSV로 변환해 앱 assets에 저장했다. 개인정보나 관리 연락처는 앱 자료에 포함하지 않았다. 처리 통계는 docs/week11/data-validation.json에 저장했다.

경로는 GeoJSON의 [경도, 위도]를 읽는다. 시설을 경로 전체의 확장 경계상자로 먼저 추린 뒤, 시설에서 각 경로 선분에 내린 수선의 거리를 계산한다. 수선이 선분 밖이면 끝점까지 거리를 사용한다. CCTV는 경로에서 50m 이내, 보안등은 40m 이내일 때 경로 시설로 센다. 한 시설은 여러 선분에 가까워도 한 번만 집계한다.

시설 밀도 D = (CCTV 수 × 4 + 보안등 수) × 1,000 / max(경로 길이 m, 100). 이 가중치와 반경은 로컬 휴리스틱으로, 공식 범죄 위험도나 실제 밝기·CCTV 가동 여부를 뜻하지 않는다. 짧은 경로의 분모 폭증을 막으려고 최소 100m를 둔다.

주변 지도 마커는 사각 경계상자 후보 중 실제 원형 반경 안에 있는 시설을 거리순으로 제한한다. 기존에는 사각형 안에서 입력 순서로 잘랐으므로 더 가까운 시설이 누락될 수 있었던 부분을 수정했다.

사용자 요청에 따라 경찰서·파출소 위치는 구현하지 않았다. 안전비상벨과 아동안전지킴이집은 좌표 자료가 없어 미구현이다. 전국이라는 파일명은 전국 전체 시설의 완전한 수록이나 최신성을 보장하지 않는다.

# 경로 선택 알고리즘 상세

1. 후보 생성: 기존 Mapbox walking API에 alternatives=true, geometries=geojson, overview=full, steps=true로 도보 후보를 요청한다. 동일 GeoJSON은 중복 제거한다. 세 옵션을 서로 다르게 보이게 하려고 임의의 직선이나 가짜 경로를 만들지 않는다.

2. 최단: 이름은 최단이지만 사용자 요구에 따라 예상 소요시간 T가 최소인 후보를 고른다. API duration이 유효하고 양수이면 이를 사용하고, 없으면 거리 / 1.2m/s로 추정한다. UI에는 추정 여부를 표시한다. 따라서 더 멀어도 시간이 짧으면 최단으로 선택될 수 있다.

3. 안전: 시설 밀도 D가 최대인 후보를 선택한다. 기존 안전 80% + 거리 20% 방식에서 시간·거리 상쇄 항목을 제거했다. 시설 지표가 더 높으면 우회 후보도 선택한다. 시설 밀도가 같을 때만 소요시간이 짧은 후보를 선택한다.

4. 추천: 후보 내 D 최솟값과 최댓값으로 S = (D-Dmin)/(Dmax-Dmin), 시간 효율 E = 1-(T-Tmin)/(Tmax-Tmin)을 계산한다. 각 값은 0~1로 제한한다. 최종 점수 R = 0.5S + 0.5E가 가장 높은 후보를 추천한다. 범위가 0이면 해당 정규화 차이는 0으로 처리한다.

예: A(100초, 시설지표 0), B(110초, 50), C(130초, 100)라면 A는 최단, C는 안전이다. 추천 점수는 A=0.5, B≈0.583, C=0.5가 되어 B를 선택한다. 중간 값은 두 경로의 좌표 평균이 아니라 시간과 시설 지표의 동등한 절충을 뜻한다.

5. 예외: 후보가 하나면 세 옵션 모두 같은 경로를 표시하고 이유를 알린다. 시설 점수가 모두 0이거나 분석에 실패하면 가장 빠른 후보를 공통 사용하고 안전 자료 부족·분석 실패 안내를 표시한다. 조회 실패는 오류 상태로 남긴다.

카드 막대는 D/(D+20)의 포화형 시각화다. 20은 표시용 스케일이며 경로 선택 공식에는 사용하지 않는다. 막대는 절대 안전점수나 안전 확률을 뜻하지 않는다.

한계: 모든 도로망을 탐색하는 Dijkstra/A* 구현이 아니라 제공된 도보 후보를 재평가한다. 따라서 가장 빠른 길·가장 안전한 길은 조회 후보 내 기준이다. 시설 밀집 구간의 보상이 시설 없는 긴 구간을 상쇄할 수 있고, 도로 조도·범죄·시설 가동 정보는 없다. 절대 최적 안전 경로에는 보행 도로망과 구간별 위험 데이터가 추가로 필요하다.
