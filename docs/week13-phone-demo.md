# 13주차 폰 앱 시연

귀가자와 수락된 보호자가 각각 로그인한 뒤 보호자 기기에서 알림을 허용한다. 경로를 선택하고 보호자를 지정해 귀가를 시작한다.

| 시연 항목 | 연동 | 확인할 결과 |
|---|---|---|
| 세션 시작·종료 | 백엔드와 FCM | 보호자 알림을 누르면 보호 중 탭이 열린다. 종료는 세션 종료를 뜻하며 GPS 도착을 보증하지 않는다. |
| 세션 화면 SOS | 실제 서버 | 길게 누른 뒤 취소하면 전송하지 않는다. 전송하면 서버 결과를 확인하고 보호자 폰에서 수신을 따로 확인한다. 위치 표시는 귀가자 폰 기준이다. |
| 위험 확인 시연 | 디버그 빌드의 모의 이벤트 | 괜찮아요, 도와주세요, 무응답을 각각 확인한다. 남은 시간은 프로필에서 설정한 값이다. 모의 시연은 실제 보호자에게 알림을 발송하지 않는다. |
| 워치 연동 | Wear Data Layer | 워치 SOS의 폰 수신 및 ACK, 위험 질문 응답, 본인 확인 후 해제를 확인한다. ACK는 폰 수신 확인이다. |
| 세션 종료 | 기기 PIN 및 서버 | 틀린 PIN으로 세션이 유지되는지, 5회 실패 안내 및 정상 PIN 종료를 확인한다. |

## 실기기 테스트 기록표
- [ ] 보호자 미등록 상태에서 세션 시작 및 SOS 결과 확인
- [ ] 위치 권한 거부 후 안내와 복구 확인
- [ ] 알림 권한 거부 후 재허용 및 보호자 기기 수신 확인
- [ ] 연결을 끊고 SOS 전송 오류 확인 후 재접속·재시도
- [ ] 백그라운드 위치 공유와 알림 탭 복귀 확인
- [ ] 위험 확인 중 화면 회전, 카운트다운 만료, 워치 연결 해제 확인
- [ ] 세션 시작 → 경로 이동 → SOS → 보호자 확인 → PIN 종료 전체 시연

알림을 누르면 서버에서 열람 권한을 확인한 진행 중 세션을 연다. 종료된 세션은 종료 안내를 표시한다.
워치 SOS는 폰에서 보호자 전송을 선택하고 확인하면 실제 발송한다. 워치 응답은 숫자 이벤트 ID와 현재 세션을 확인한 뒤 PENDING 상태에만 적용한다. 디버그 워치 질문은 mock ID를 사용한다.
